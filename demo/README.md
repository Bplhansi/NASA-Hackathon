# 🌍 Earth Detective — Project Demo

**NASA Space Apps Challenge 2026**

Earth Detective is an interactive environmental investigation platform that uses NASA satellite imagery and natural-event data to help users explore changes happening across our planet.

### 🚀 Features
- **Detective Scan:** Investigate environmental changes in the Aral Sea, Lake Urmia, and Lake Mead.
- **Evidence & Findings:** Explore experimental water-coverage trends using satellite image analysis.
- **Time Machine:** Compare satellite images from different years.
- **Earth Feed:** Discover natural events using NASA EONET data.
- **Solutions Lab:** Suggest and vote on ideas to protect our planet.
